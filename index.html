Vajra Linux

A custom fork of MX Linux that I designed and built myself. It adds a simplified desktop layout switcher so users can change their interface with ease, and full support for Indian regional languages — the locale, fonts, and input methods needed to make Linux genuinely usable for people who aren't comfortable in English. Building it meant working hands-on with system internals, package customization, and localization frameworks.
